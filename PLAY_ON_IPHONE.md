# 🎮 How to Play Hedgehog Skiing on Your iPhone

## 🚀 Quick Start (3 Easy Steps!)

### Step 1: Enable GitHub Pages
1. Go to your repository on GitHub: https://github.com/Jack-Square68/hoggames
2. Click on **Settings** (top menu)
3. Scroll down to **Pages** (left sidebar)
4. Under "Build and deployment":
   - Source: Select **Deploy from a branch**
   - Branch: Select **main** and **/ (root)**
   - Click **Save**
5. Wait 1-2 minutes for deployment

### Step 2: Access Your Game
Once GitHub Pages is enabled, your game will be live at:
```
https://jack-square68.github.io/hoggames/
```

### Step 3: Save to Your iPhone
1. Open the URL above in Safari on your iPhone
2. Tap the **Share** button (square with arrow)
3. Tap **Add to Home Screen**
4. Name it "Hedgehog Skiing" 
5. Tap **Add**

Now you have the game as an app icon on your iPhone! 🎿🦔

---

## 📥 Alternative: Download and Play Offline

If you want to play without internet:

1. On your iPhone, go to: https://github.com/Jack-Square68/hoggames/blob/main/index.html
2. Tap on **Raw** button
3. Long press anywhere on the page
4. Tap **Share** → **Save to Files**
5. Choose a location and save
6. Open **Files** app → tap the saved file → play!

---

## 🕹️ Game Controls

- **Tap LEFT side** of screen → steer left
- **Tap RIGHT side** of screen → steer right
- **Avoid**: Trees 🌲 and Rocks 🪨
- **Collect**: Golden snowflakes ⭐ (+100 points)
- Speed increases as you score more!

---

## ❓ Troubleshooting

**Black screen?**
- Make sure you're using Safari (not Chrome)
- Clear Safari cache: Settings → Safari → Clear History and Website Data
- Try the GitHub Pages URL instead of the raw GitHub URL

**Game too fast/slow?**
- The game adapts to your device's performance
- Higher scores = faster gameplay!

**Not loading?**
- Check your internet connection
- Make sure GitHub Pages is enabled (Step 1 above)
- Wait a few minutes after enabling GitHub Pages
