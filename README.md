# 🎿 Hedgehog Downhill Freeride Skiing Game

A fun downhill skiing game featuring your adorable hedgehog character! Play directly on your iPhone with no installation required.

## 🎮 How to Play on Your iPhone (While Traveling)

### Option 1: Play via GitHub Pages (Easiest!)
1. Open Safari on your iPhone
2. Go to the GitHub repository link (will be provided after push)
3. Tap on `game/hedgehog-skiing.html`
4. Tap "Raw" button to view the raw file
5. The game should load directly in Safari!

### Option 2: Save to Files App
1. On your iPhone, open Safari and go to this repository
2. Download the `hedgehog-skiing.html` file
3. Save it to your Files app (tap Share → Save to Files)
4. Open the Files app and tap on the file to play!

### Option 3: Direct Link (After Setup)
Once pushed to GitHub, you can access it directly via:
- GitHub Pages URL (if enabled)
- Raw GitHub content URL

## 🕹️ Game Controls

- **Tap LEFT side of screen** - Steer left
- **Tap RIGHT side of screen** - Steer right
- **Objective**: Ski downhill, avoid trees and rocks
- **Bonus**: Collect golden snowflakes for extra points!
